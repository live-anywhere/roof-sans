Roof Sans

Roof Sans는 LiveAnywhere 앱과 웹 페이지를 위한 가변 폰트입니다. 파일 하나에 굵기 축(wght)이 있어 Thin(100)부터 ExtraBlack(1000)까지 씁니다. 바탕은 원티드 산스이고, 원티드 산스에 없는 글자를 프리텐다드 JP와 소스 한 산스로 채웠습니다.

  • 원티드 산스에 있는 글자(한글, 라틴, 숫자, 문장부호, 기호)는 원티드 산스 그대로입니다.
  • 한자, 가나, 일본어 문장부호는 프리텐다드 JP 그대로입니다.
  • 프리텐다드 JP에 없는 GB 2312 한자 3,260자와 한자 2,212자의 중국어 간체 자형은 소스 한 산스 CN에서 가져와 프리텐다드 JP 한자의 크기와 굵기에 맞췄습니다. 간체 자형은 중국어로 지정한 글에만 적용됩니다.
  • 그 밖에 프리텐다드 JP가 더하는 글자(베트남어 등 라틴 확장, 그리스·키릴 문자, 화살표, 수학 기호, 단위, 원문자, 분수)는 원티드 산스의 부품으로 다시 만들거나 원티드 산스의 높이·굵기·기호 축에 맞췄습니다. 그래서 섞어 써도 튀지 않습니다.
  • 원티드 산스에는 400보다 가는 굵기가 없습니다. 100–300은 원티드 산스의 글자마다 400에서 550으로 가는 변화를 반대쪽으로 이어 만들었고, 400 이상은 원티드 산스와 같습니다.

Thin부터 ExtraBlack까지입니다.

원티드 산스에는 Regular(400)보다 가는 굵기가 없습니다. Thin·ExtraLight·Light(100–300)는 원티드 산스의 글자마다 400에서 550으로 가는 변화를 반대쪽으로 이어서 만들었고, 한글 획의 양이 같은 굵기의 프리텐다드 JP와 같아지는 지점에 맞췄습니다. 그래서 한자와 가나가 한글 옆에서 같은 굵기로 보입니다.

한국어·일본어·중국어 간체, 그리고 라틴·키릴·그리스 문자 560여 개 언어

아래 목록은 폰트에 실제로 들어 있는 글자를 기준으로 계산했습니다. 라틴·키릴·그리스 문자 언어는 언어별 필수 문자 데이터베이스인 Hyperglot으로 확인했고, 지금 쓰이는 언어의 기본 문자 집합이 기준입니다. Hyperglot에 데이터가 없는 일본어와 한자는 국가 표준 문자표와 하나씩 비교했습니다.

괄호와 문장부호: 한국어와 일본어

원티드 산스가 이미 가진 괄호와 문장부호 13자는 한국어 모양이 기본입니다. 문서 언어를 일본어(lang="ja")로 지정하면 프리텐다드 JP의 일본식 모양으로 바뀝니다. 강조한 글자를 비교해 보세요.

lang="ko"
今日は、とても暑い。「東京」『確認』【注意】 ID「abc」
lang="ja"
今日は、とても暑い。「東京」『確認』【注意】 ID「abc」

중국어 간체 자형

중국어 간체는 lang="zh-CN"으로 지정합니다. zh·zh-Hans·zh-SG도 같은 자형을 고릅니다. 따옴표는 영문 단어 주위에서도 양쪽이 같은 전각 폭입니다.

lang="ja" · 기본 한자 자형
直骨安本 啊阿埃！他说“OK”。：；？
lang="zh-CN" · 중국어 간체 자형

한자: 일본식과 한국식

한자는 반대입니다. 기본은 프리텐다드 JP의 일본식 자형이고, 한국어(lang="ko") 또는 ss20에서는 한국식 자형 537자로 바뀝니다.

웹

웹에서 쓰기

jsDelivr에서 동적 서브셋 CSS를 불러오고, 글꼴 이름 Roof Sans를 씁니다.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/live-anywhere/roof-sans@__RELEASE_TAG__/dist/web/roofsans-dynamic-subset.css">
body { font-family: 'Roof Sans', sans-serif; }
  • 폰트는 작은 WOFF2 파일 여러 개로 나뉘어 있고, 브라우저는 페이지에 나오는 글자가 든 파일만 받습니다.
  • 굵기는 가변 축에서 나옵니다(font-weight: 100 1000). 100보다 작은 값은 100으로 그립니다.
  • 언어별 자형은 HTML lang 속성을 따릅니다. 일본어 문장부호는 lang="ja", 중국어 간체 자형은 lang="zh-CN", 한국식 한자 자형은 lang="ko"입니다.
  • 파일 경계를 넘는 조판 규칙은 적용되지 않습니다. 예를 들어 한글 바로 뒤의 쌍점(:)과 말줄임표(…)는 기본 높이에 그대로 있고, 기본 라틴 글자와 확장 라틴 글자 사이의 커닝(T + ō 등)이 빠집니다. 이런 부분이 중요하면 폰트 전체를 파일 하나로 불러오는 roofsans.css를 쓰세요. 이 페이지도 파일 하나로 불러옵니다.
Flutter

Flutter에서 쓰기

RoofSansVariable.ttf 파일 하나를 등록하고, weight 항목 없이 선언합니다. FontWeight는 그대로 씁니다.

flutter:
  fonts:
    - family: RoofSans
      fonts:
        - asset: assets/fonts/RoofSansVariable.ttf
Text(
  '「東京」へ行きます',
  style: TextStyle(
    fontFamily: 'RoofSans',
    fontWeight: FontWeight.w700,           // Flutter 3.41 이상: wght 축으로 전달
    locale: const Locale('ja', 'JP'),      // 일본식 괄호·문장부호
  ),
)
Text(
  '欢迎回来！他说“OK”。',
  style: TextStyle(fontFamily: 'RoofSans', locale: Locale('zh', 'CN')),
)
  • Flutter 3.41 이상에서는 FontWeight가 wght 축 값으로 전달됩니다. 그보다 오래된 버전에서는 fontVariations: [FontVariation('wght', 700)]을 함께 지정하세요.
  • 굵기 축은 100(Thin)부터 1000(ExtraBlack)까지입니다. w100–w300은 Thin·ExtraLight·Light로 그려집니다.
  • 일본식 괄호가 필요하면 TextStyle(locale: Locale('ja', 'JP'))를 지정하세요. Flutter 웹에서는 앱 로케일만으로는 적용되지 않았습니다.
  • 중국어 간체는 TextStyle(fontFamily: 'RoofSans', locale: Locale('zh', 'CN'))으로 지정하세요. 한자와 문장부호에 중국어 자형이 적용됩니다. Flutter 웹에서는 TextStyle에 로케일을 지정해야 하며, Android는 아직 검증하지 않았습니다.
  • 줄 높이는 PretendardJP와 같습니다(hhea 1950 / −494).
